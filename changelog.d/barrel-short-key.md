### Fixed — `--for` follows TS/JS namespace re-exports, proves a written qualifier, and never answers an unresolved name with nothing

- `--for` `<reexports>`: a TS/JS namespace hop is now a row. `import * as X from './m'` followed by a local `export { X }` (or `export { X as Y }`), and `export * as X from './m'`, publish the whole module under `X`; the row says `ns="X"`. Behaviour change: `export * as ns from` used to be no row at all (the old legend said so); it is now an `ns=` row, and `test/reexportcheck.sh` arm T2 was rewritten with it.
- `--for` `<reexports>` on a qualified subject (`Q.leaf`, `Q::leaf`): a definition named `leaf` is listed only when `Q` is proven for it (its owner scope is `Q`, a namespace hop publishes it under `Q`, or its file stem or a directory spells `Q`); the definition carries `q=` and the chain that proves it prints first. A same-named definition that cannot prove `Q` is no longer listed, so a qualified cued task may now print fewer definitions than before. A subject that is one code-shaped name (the whole task) now prints its chain without a cue word.
- `--for`: a name-exact route that resolved no definition (`reason="no_candidates"`, empty `<sigs>`) now prints a `<shortkey>` block with a fallback ladder, each rung named: `leaf` (a dotted key's last segment, filtered by the same qualifier proof; exactly one proven definition is `exact="1"` and its body is printed, several are hedged with `cands=`, none is `q_unmatched="1"`), `substring` (definition names containing the key, never exact) and `literal` (declaration-shaped source lines the index does not store as definitions: `using X =`, `typedef … X;`, `type X`, `#define X`, `… as X` on an import line, `const`/`let`/`var`/`static X`, `X =` at column 0; comment lines are never rows). Every block carries `next=`; rows are capped at 6 per rung with `total=`, a printed body is cut past 8192 bytes with `truncated="1"`. XML answers only; under `--token-budget` a held marker prints instead. `RIPWIRE_NO_SHORT_KEY=1` turns it off.
- Measured on the practice questions this targets: `--for=Completions.getCompletionsAtPosition` on TypeScript went from a 1.3 KB answer with no definition to the namespace hop and the definition's body; `--for=ColumnPtr` (ClickHouse) and `--for=ExprType` (RisingWave) now name the `using` / `use … as` lines that declare them. Gate: `test/barrelshortkeycheck.sh`.
