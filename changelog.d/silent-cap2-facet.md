### Added — `--quality-delta` names a stop at a constant limit that leaves no trace (`defect="silent-cap"`, report-only)

- A new defect-shape facet for C++, always `sev="minor"`, never gating. The site is found by structure: a counter the function grows (`++n`, `n + 1` passed on, `C.size()` of a list it appends to) against a constant or a fixed array's size, as a loop condition beside another one, a bare `break` / `continue` / `return`, a keep with no else, or `X.substr( a, kMax )`.
- The row prints only when nothing can tell a reader the limit was reached: the limit is named nowhere else in the function or in another function of the tree outside such a stop, no `static_assert` names it, nothing counts or flags beside the stop, and a returned value is one the function returns elsewhere too. `why=` names the limit.
- Measured (docs/EVALS.md, SILENT-CAP-2): 12 of 43 CodeRabbit "disclose this cap" seeds found (the earlier prototype found 3); 12 of 17 rows on this tree are real (71 %, Wilson 95 % [0.47, 0.87]). That is below the 80 % a gating facet needs, so the row is a question to answer, and the legend says so.
- The defect-shape site value gained an extension mark so a ninth facet fits without moving released ack keys: facets 0..6 keep their values, and only count-drift's (new in the previous change) moved. `kQSnapCacheScheme` moves to 42.
