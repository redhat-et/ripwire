### Fixed — `--for` gives an unresolved code-shaped name inside a sentence the same fallback ladder a bare name gets

- `--for`: a task the route reads as words (`definition of ChunkPtr, the lookup is empty`, `where does Wrong.formatDate come from`) now prints the `<shortkey>` fallback ladder when it holds exactly one code-shaped name and no definition of that name resolved. Code-shaped means a qualified spelling (`Q.leaf`, `Q::leaf`, every segment starting like an identifier, a leaf that is no file or host suffix) or a camelCase / snake_case word; a plain capitalised word (`Widget`, `Python`) is not one, and a bare word that is a segment of the qualified spelling beside it counts as that name. Unresolved means a bare name that no symbol in the index carries, or a qualified name whose fully proven definition the answer did not print; a qualified spelling that is an indexed file's module path (`http.server` for `Lib/http/server.py`) or basename names a file and gets no ladder. The block carries `from="sentence"`; its rungs (`leaf`, `substring`, `literal`), the qualifier proofs, `exact=`, `next=`, the row caps, the held marker under `--token-budget` and `RIPWIRE_NO_SHORT_KEY` are those of the bare-name ladder. A task with two or more code-shaped names, a name that resolves, or no code-shaped name prints no block. Gate: `test/barrelshortkeycheck.sh` arms D1-D9.
