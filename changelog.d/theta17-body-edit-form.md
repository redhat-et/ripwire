### Added — `RIPWIRE_BODIES_EDIT`: an edit task's top-file bodies become act ranges (default off)

With `RIPWIRE_BODIES_EDIT` set (and neither `--bodies=` nor `RIPWIRE_BODY_POINTERS` given), a `--for` task that reads as an edit (its first word an edit verb, after an optional `scope:` prefix) serves page 1 with every body in its top file — the act line's first path; a page without an act line is served as it is — as a lean `<skip p= n= l= e=/>` row in place, and adds each `P:L-E` to `<act read=>`. Bodies in other files stay inline. The page ends where it ended, its root says `body_form="edit"`, and one legend comment defines the form. Why: on 141 recorded Claude Code sessions the agent Read the file before editing every time a delivered body sat in the file it edited, so that body was carried twice for the rest of the session. The default answer is unchanged byte for byte. Gate: `test/bodyeditcheck.sh`.
