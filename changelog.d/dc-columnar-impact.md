### Changed — `--format=columnar` carries the declined-call rows as arrays, and a windowed `--callers` / `--impact` root names the complete call

The columnar form removed 46 % of a complete `--impact` answer's symbol rows and none of its `<dc>` rows, which it printed verbatim: on the 32 windowed impact cells of the registered population (39 symbols, five corpora) those rows were 17,479,478 of 30,101,002 B, 58.1 % of the answer.

- Under `--format=columnar`, an answer of `--callers`, `--callees` or `--impact` that lists more than 16 declined call sites (the default cut, so only one whose `--limit` lifted it) carries them as one `<dcols n= via="declined" fields=…>` block of parallel arrays after `</cols>`: `path` (an index into the answer's one `<paths>` table), `in`, `line`, `cands`, and `gate`, `bound`, `of_def`, `cand`, `cand_more` where a site has them. An empty cell is an absent attribute. Every `<dc>` row can be rebuilt from the block byte for byte. At 16 sites or fewer the form prints the rows as before: a table that small is not smaller as arrays once its definition is paid for. The XML form, `--json` and the MCP answers are unchanged.
- Measured at `--limit=<total>` on those 32 cells: 30,101,002 B to 18,524,942 B (−38.5 %), the declined-call payload −66.2 % with its added path-table entries counted, the legend +1,974 B.
- A `--callers` or `--impact` root that windows (`has_more="1"`) carries `all_next="--VERB=X --format=columnar --limit=N"`: the one call that lists every row. `N` is the larger of the row total and the declined call sites, because `--limit` sizes the declined-site cut too: at `--limit=<total>` 12 of the 32 complete answers still cut `<dc>` rows and named a second call. The attribute is written from the window the verb computed for that answer, never predicted. It costs about 184 B on a windowed first page (the attribute and its legend clause). `--json` and the MCP `impact` / `find_referencing_symbols` answers carry it as well; `RIPWIRE_NO_WINDOW_HANDOFF=1` turns it off.
- No answer moves from windowed to complete in one call: `--impact` windows on a row cap, and the default form is unchanged. What moves is the second call: the default page plus the named call is 20,951,305 B on the 32 impact cells against 41,221,482 B for the default page plus `--limit=<total>` in XML.
- The file roll-up is unchanged. It is absent from a complete answer and already withheld, by name, from the columnar form.

`test/dccolumnarcheck.sh` rebuilds every `<dc>` row from the block and compares it with the XML form, requires the pointer on exactly the windowed roots (0 false positives, 0 false negatives) and the named call to be complete at both grains, and turns seven mutations of the real binary red, three of which lose a declined-call fact.
