### Fixed — `--grep` no longer holds hits back by span tier in a file whose parse degraded

`--grep`'s default tier serves code and holds comment and string hits back (`suppressed_comment=` / `suppressed_string=`). In a file whose indexed parse holds ERROR nodes (its row carries `parse_degraded="1"`) that tier came from the same grammar that failed there: fzf's `shell/completion.zsh`, parsed with the bash grammar, had its definition and both calls of `__fzf_list_hosts` held back as "string", and the answer named no held-back file. A hit in such a file is now unclassified: it is served, counted in `tier_unclassified=`, and never suppressed. A string or comment hit in a clean file is held back exactly as before. The `tier_unclassified=` reading says so in both legends. Lane BX2; `test/grepdegradedcheck.sh`.
