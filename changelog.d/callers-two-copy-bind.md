### Changed — `--callers` binds the source copy of a two-copy method and names the copy

`--callers=Owner.method` used to refuse when the name had two bodied definitions and one of them was a copy, such as vscode's `extensions/copilot/src/util/vs/…` tree, whose files open with "DO NOT modify, this file was COPIED". Now, when every definition left after the test-path and bodyless ones are dropped is a copy except ONE, the source one answers. A copy is a file under a CI or tool dot directory, a vendoring directory or the demo/generated tier, or a file whose head declares it generated or copied. The root carries `narrowed=` as before, plus `copy_p=` (each copy as `p:line`) and `copy_next=` (the callers call on the first copy). MCP `find_referencing_symbols` and the `callers` batch verb answer the same copy (`copy_p` / `copy_next` / `copy_note`). Two source definitions, or none, still refuse. `--for` is unchanged. New arms (d6)-(d8) and (e4) in `test/gvassemblycheck.sh`.
