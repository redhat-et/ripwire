### Changed — `--for` exemplar touch rows name the definition that holds the line

Each `<touch p="file:line">` row of an add-a-new-X answer now carries `n=`, the innermost indexed definition whose span holds that line, spelled as the other `--for` rows spell it (`Owner.name` / `Owner::name` for a member). A line no definition holds (an import or `export *` line) prints no `n=`, and neither does a line two separate definitions share. On kubernetes the `default_plugins.go:55` row now says `getDefaultPlugins`, on RisingWave `strong.rs:284` says `Strong::is_null_function_call`, and on TypeScript `commandLineParser.ts:1228` says `commandOptionsWithoutBuild`: the function to edit, not only the line. About 60 bytes per answer that has touch rows. New gate arm e6 in `test/forexemplarcheck.sh`.
