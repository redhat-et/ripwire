### Added — `--pack-task` names the files that usually change with the task's files (`<partners>`)

Across 752 real bug-fix commits the median fix edits two files, and developers miss a related change 45.7% of the time; `--pack-task` named the files a task touches and never the ones that historically change WITH them. The bundle (and the MCP `explore` verb, which shares its assembler) now carries a `<partners>` block after `<tests>`: the co-change partners of the ranking's first three distinct files (the key body's file first), merged by `--situ`'s own rule, which is now one shared function (`mergeSeedPartners`, `src/situ.h`) instead of two inline copies. Rows are names and support counts only, `<f p= together=>`, where `together=` is the commits a partner shares with its best seed (3 or more). The window is the last 500 commits (the `--for` co-change boost's window: bounded on any repository, and a function of HEAD alone), and the element says what it read and what it left out: `window=`, `commits=`, `seeds=`, `bulk_skipped=N` (commits over 30 indexed files, left out of every co-change miner here and now counted on this one), the history policy of this walk in #777's names (`bots_skipped=`, `agent_commits=`, `renames=`, each present when non-zero), and `shallow="1"` on a depth-limited clone. The block takes up to 3% of the budget, first from what the other sections left and then from the file tail's share, and tops up in the reflow lap; a cut reads `capped="1" partners_cut=N`, and the element is still printed when no row fits. With no repository, no commit in the window, a shallow clone with none, a multi-root run or nothing ranked, there is no block and the root says why in `partners_none=`. Also fixed: the history-policy comment the history verbs print after their answer spelled `--include-bots` inside an XML comment, so `--hotspots`, `--cochange`, `--situ`, `--rank-by=churn` and `--quality-delta` answers did not parse as XML whenever it printed; it is now dash-collapsed like every other comment. Measured on this repository, 5 tasks at the default budget: the answer grows by a median 409 B (max 504 B; one task 95 B smaller, its tail re-cut), the block itself is 146–320 B and its compact readings about 330 B; the walk adds about 0.3 s warm. New gate `test/packpartnerscheck.sh`.
