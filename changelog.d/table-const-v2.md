### Added — a `--for` task about a table or a registration reaches the sites of the identifier it names

When no other literal of the task has a source site, `<lit>` makes a last try, `shape="table"`. It needs one of these in the task's own words, outside backticks: a registration word (`register`, `registered`, `registry`, `registrar` and their forms), `table`, `compile-time` or `compile time`, `add a new` or `implement another`; or `default` or `handler`, which print only when a site reads as a table row. Its anchors are the task's backticked spans, then identifier-shaped words, then a plain word after `like`, `alongside` or `following`: any word that is not backticked must be the name of a symbol in the index. A backticked span or a word after `like` is the thing to read and prints its sites; a bare identifier-shaped word prints only beside a real table row, so `add a new test for run_it` or `fix register allocation in run_it` print nothing, and so does a backticked span right after `to` in an add task (`add a new argument to` run_it, the thing changed). A hit stands on word edges; a hit inside a longer word is counted in `longer=`.

Each anchor with a source site prints its own `<lit>`, the legend on the first only. A site that reads as a table row ranks first, wherever it stands: a map or dict key, a list member, a `{ name, ...` row or a call beside a sibling of the same shape at its indent, under an opener the allowlist knows, or a macro or ALLCAPS call outside any function (a Go map entry, a Rust macro row, a C X-macro line). The allowlist's openers are data: an assignment, a `return` or a key whose value is a bracket, a typed composite (`[]T{`, `map[K]V{`, `new T[] {`), a macro's bracket or a named wrapper (`Object.freeze({`, `new Map([`, `frozenset({`, `Map.of(`); `export default {`; an enum's members; a `#define`; a struct literal outside a function. Anything else makes no claim: a call's arguments, a callback, a statement, a `struct`, `interface` or `type` declaration. Such a row carries `tbl=`, the line that opens the table (`item` for a top level call), and the first four carry `lines=a-b`, the lines after them. This is a reading of the line's text, not of the parse; a row with no `tbl=` is no claim either way. Inside a function body a call is a statement and never a row. Past 4,096 source sites the rest are not read for a table row: `read=` says so, and an anchor that needs a row and has none in those read is counted by `<lit_capped>`. Rows stop at 32 per anchor and all the elements of a task at 40,000 bytes, cut on a row boundary with `capped="1"` and `next=`. At most 3 anchors print and 4 are scanned (an anchor with no site costs a scan); every anchor past a cap, or left without room, is counted by `<lit_capped>`. Everything before the element stays byte-identical. Gate: `test/forliteralcheck.sh`.
