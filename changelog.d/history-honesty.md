### Changed — churn and co-change leave bot commits out, and an exact file move is no longer churn

The history walks behind `--hotspots`, `--rank-by=churn` / `churn-decay`, `--cochange`, `--situ` and `--quality-delta`'s short-horizon churn now read whose commit it is. A commit by a bot author (a name or email ending in `[bot]`, or one of a few listed automation accounts such as Dependabot's, Renovate's and GitHub Actions') touches nothing, so a lockfile a bot rewrote fifty times no longer tops the hotspots or the co-change pairs; the answer ends with `bots_skipped=N`, and the new `--include-bots` keeps them (`bots_included=N`). A commit whose `Co-Authored-By:` trailer names a coding agent is kept and counted (`agent_commits=N`). The walk now reads each change's blob ids (`--raw --no-abbrev`, still no blob read, so a blobless clone walks as before) and pairs a delete and an add of the same blob in one commit as an exact move: a pure `git mv` is no churn event and no co-change, and the moved file's older history follows it to its new path (`renames=N`). A block of lines moved inside or between files is one edit of each file it touches, as before. The three counts ride one comment after the answer, the same way `history_cut` does, and only when one is non-zero. `--owners` is unchanged. The qchurn cache keys on the bot policy (the scheme it moves to is stated by the clock-cut fragment, which bumps it again). A side effect: the `__C__` merge-path collision that `test/gitframingcheck.sh` used to pin as disclosed is now closed. Measured against the pre-change binary, `--hotspots` top 20: this repository keeps the same 20 files (2 change place, 7 lose a little churn; 23 bot commits and 34 exact moves); kubernetes swaps 3 of 20 and 6 of the rest change place (682 bot commits, mostly merge commits by `kubernetes-prow[bot]` that `-c` lists whenever both sides touched a file, and 345 exact moves). Asking git for exact renames instead (`-M100%`) was measured and refused: it turns off the combined diff's fast path, 0.64 s → 6.13 s of git on kubernetes' 12-month window; the walk as shipped costs what it cost before (0.47–0.52 s).
