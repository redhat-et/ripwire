### Added — `--flags` reports Bash environment-variable reads, and answers `--json` (#641)

In `.sh`, `.bash` and `.zsh` files, every `$X` and `${X…}` is now an env read (`kind="env"`) unless the same file assigned `X` earlier. Each read row says how the script reads the name: `form=` is `required` (`${X:?}`), `default` (`${X:-d}`), `unset-default` (`${X-d}`), `settest` (`${X:+w}` or a `-n`/`-z` operand), `assign` (`${X:=d}`) or `plain`; `colon=` says whether an empty value counts as unset; `default=` carries the literal default word. Assignments (`X=`, `export X=`, `local`, `declare`, `readonly`, `read`, `for`, `mapfile`, `getopts`, `printf -v`) are listed as `<write>` rows rather than reads, and a write that reads its own name (`X="${X:-}"`) passes the caller's value through instead of hiding later reads. A prefix assignment (`X=1 cmd`) reaches only that command and is not a write; a function's `local` (or a `declare` without `-g` inside one) hides reads only to that function's end; an element write `X[i]=v` hides later `${X[…]}` reads but not the scalar `${X:?}`. `-n`/`-z` makes a read a set test only as an operand of `[`, `[[` or `test`. Names Bash or the login always sets (`BASH_*`, `PWD`, `HOME`, `PATH`, …) carry `ambient="1"`. A shell file with a `GENERATED … DO NOT EDIT` comment banner is skipped and counted as `generated_skipped=` on the root. `--flags` joins the `--json` allow-list; keys mirror the XML attributes.

A repository with no shell scripts gets byte-identical `--flags` output (checked on `test/flagsfix` and `src/`, full and compact legend). On fullsend-ai's agents tree, a `bash-env-contract` check fed by `--flags --json` reproduces its regex extractor's findings byte for byte, and drops two false assignments the regex made (`echo "  X=${X}"`). Precision is lexical within one file, like every other `--flags` lane: a name set through `eval`, `printf -v "$1"` or a function defined after the read still reads as external.
