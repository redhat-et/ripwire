### Fixed — a Rust prelude call or a macro with no in-tree binding no longer binds to a same-named definition

`Ok(x)`, `Err(e)`, `Some(x)` and `drop(x)` with no binding of the name written in the caller's file (a definition there, or a `use` that names it) used to bind to whatever the tree defined under that name: a serde serializer's associated `type Ok = ();` (also in the caller's own file), a `type Err` alias, a function nested in another function and reached through `use super::*;`. Only a definition a bare call can name now cancels that: a function in scope (a nested one only inside the function that holds it) or a tuple struct, never an associated item, a type alias, an enum or a braced struct. A macro invocation (`assert!`, `json!`, `format!`, `write!`, `panic!`) bound by name to a function, module or type of the same name. Those calls are now counted as calls outside the tree (`external=` in the map header) and carry no edge. A macro invocation binds to an indexed `macro_rules!` of its name, or to a `#[proc_macro]` function its file's `use` names (a procedural macro such as `sql!`; a plain or nested function of the name is no macro); a user's own `Ok` type reached through a `use`, a same-file definition, and a local `macro_rules! assert` called in its own file keep their edges. A `macro_rules!` without `#[macro_export]` is in scope only where Rust puts it: its own file, its child modules (a crate root named by Cargo's `[lib] path` owns its directory like `lib.rs`), the parent module's scope when the module is declared `#[macro_use]`, or where a `use` names it; elsewhere, including a `src/bin/` file or a `main.rs` beside the library root, a call of that name is the standard or an outside crate's macro. Not read yet: a module declared with `#[path = ..]` (its calls of a parent's macro are counted `external=`), and source order inside a module. A Clojure `defmacro` called as `(name ..)` keeps its edge.

Five Rust member names joined the standard-member gate after a hand sample of their unproven calls: `.expect()`, `.into()`, `.join()`, `.lock()` and `.status()` (0 of 40 sampled calls on Zed bound to the right definition; 2 of 20 on Nushell). Such a call with no receiver proof is now declined and counted in `declined_calls=`; a receiver typed as an in-tree class, or an impl's own `self.expect()`, keeps its edge.

Rust macro invocations now carry `role="macro"` instead of `role="call"`; the cache is re-parsed once (parser version 297).
