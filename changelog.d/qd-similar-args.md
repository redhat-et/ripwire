### Added — `--quality-delta` marks a new or grown list of adjacent same-typed parameters (`similar=`), report-only

A C or C++ function that is new in the change, or whose parameter list grew, and that now holds three or more adjacent parameters of one written type with different names (`g( at, nameAt, nameEnd, fileId, line )`) gets `similar="N"` on its `params` row, N being the longest such run. A call that swaps two of them compiles and runs wrong. A row the `params` kind already reported keeps its severity and gains the attribute; any other function gets a new `params` row with `sev="minor"` (`was=` and `now=` stay parameter counts). `similar=` never gates: the exit status is what it was without it. On a range (`--quality-delta=A..B`), `--quality-kinds=` without `params` drops the rows, as it drops every `params` row. A run of two (`f( task, answer )`, `begin`/`end`) is not reported: on the tidy-681 ref pair (1bbfcebc1..b0f829d69) runs of two were 160 of the 184 rows, so the shortest reported run is three (owner decision, 2026-11-18). The scanner reads only the signature text: unnamed parameters, packs, `bool` and iterator types are not counted, and two spellings of one type (an alias beside its target) are two types. A run made by retyping a parameter at the same count is not seen, because the baseline stores parameter counts only. Other languages are not read.

Counting runs of two, on the 83 bugprone-easily-swappable-parameters findings of #681 the scan scored precision 0.97 and recall 0.90; on a hand-labelled sample of the functions clang-tidy does not flag, 0.78. `--for`, the map and `--deps` are unchanged. The full and compact legends define `similar=` when a row carries it.
