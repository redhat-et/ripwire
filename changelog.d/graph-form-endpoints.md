### Added — `--for "path from A to B"` shows both sides of a missing path

When the path verb a `--for` task already runs (`path from A to B`) finds no directed path (`reachable="0"`), a new `<path_gap from= to= reachable="0">` block follows inside the graph block. It carries A's callees and B's callers, each the plain `--callees` / `--callers` answer cut at 10 rows (`count=` is the total, `next=` the page after) with its own legend, and says a name common to both sides is a candidate link, not a proven path. A found path prints exactly what it printed before, and the ranking and `route=` are unchanged. The block is CLI only; the MCP `for` verb does not print it. New gate `test/graphformendpointscheck.sh`.
