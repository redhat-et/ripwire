### Added — an alias leads to what it names: `--for` follows the chain, `--uses` lists the sites written through it

`--for=ColumnPtr` printed `using ColumnPtr = COW<IColumn>::Ptr` and stopped there: what the alias stands for (`COW::Ptr`, then `using Ptr = immutable_ptr<Derived>`, then the class `immutable_ptr`) and the class it points at (`IColumn`) each took another call. A `--for` answer now ends with an `<aliases>` block when the name the task spells (the route's name, or a sentence's one code-shaped name) has an alias definition: one `<chain>` per distinct walk, one `<h via="alias">` row per definition reached with its declaration text and `d=` hops, the template argument of the first target as `arg="1"` (the pointee of a smart-pointer alias) with its member count and first names, and a `<leaf>` for a spelling no definition in the tree binds (`std::shared_ptr`, a template parameter's member). The walk is bounded (4 hops, 3 definitions per spelling, 3 chains, `cycle="1"` / `depth_capped="1"` / `capped="1"` when they cut), sits outside `est_tokens`, and under a token budget prints a one-line held marker. `RIPWIRE_NO_ALIAS_HOP` turns it off.

`--uses=IColumn` now also lists the sites written as an alias whose chain reaches `IColumn` (`ColumnPtr`, an alias of that alias, `std::shared_ptr<IColumn>`), each marked `via="alias" alias="ColumnPtr"`, after the direct rows and counted in `count=`; `via_alias=` counts them and `alias_namesakes=` says when another definition shares an alias's name (its sites are name-matched in too). The columnar form counts them as `alias_sites_held=` instead of listing them. A definition inside another translation unit's source file (an example program's own `class IColumn`) is not what a header alias names while another definition of the name remains.

C++ only for now (headers included): its alias definitions are the ones that record a target. A TypeScript or Rust `type X = Y`, a Rust `use … as`, and a Python module alias get no block yet. The MCP and LSP `uses` answers are unchanged. Gate: `test/xfaliashopcheck.sh`.
