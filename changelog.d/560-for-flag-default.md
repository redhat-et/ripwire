### Added — a `--for` task that names a `--flag` reaches the call that defines it and the default it takes

A task naming a flag (`kubelet --max-pods`, `How does the kubelet use the --max-pods flag?`; a `--` token whose name holds a hyphen, or a `--` name of 5 bytes or more right before the word flag or option) now gets a `<lit shape="flag">` when no earlier literal of the task has a source site. Its rows are the sites where the name is a whole quoted string (`"max-pods"`, `"--workers"`; its definition is one of them, an invocation or a lookup another); a name with no inner hyphen (`--compress`) is a site only in its dashed form (`'--compress'`) or as an argument of a flag-definition call (`fs.Bool("verbose", ...)` or a TCLAP `ValueArg<T> name(...)`), never a dict value, an `__all__` entry or an error message. Any other source hit (usage text, a longer flag such as `max-pods-per-core`) is counted in `mention=`. On the first such row that has one, `def=` is the default of a flag-definition call, read from the text: a `default=`, `default_value=` or boost `default_value(10)` argument, else the default slot of a Go flag, pflag or cobra call (the argument after the name, two after it for the `P` form such as `StringVarP`), never a usage sentence. A call that is no such flag call (an `exec.Command(...)` invocation, a nushell `.named("end-date", SyntaxShape::String, ...)`, an argparse alias `"-v"`) has no `def=`. When `def=` names a field (`c.MaxPods`), `<ld>` rows list the constant writes of that field (`obj.MaxPods = 110`, `MaxPods: 110`, never a copy `out.MaxPods = in.MaxPods`) in code that names the type of the receiver in `def=` (its parameter type, a package variable's declared type or its own name; a name match, no type check; a receiver with no type found lists none), functions and files named for defaults first, at most 2, with `writes=` counting all of them. Measured on kubernetes-05 (stored and both natural wordings): the `max-pods` registration row prints with `def="c.MaxPods"`, and the first `<ld>` row is the 110 default in `SetDefaults_KubeletConfiguration`. Gate `forliteralcheck` F1-F28 covers Go pflag (plain and shorthand), Python argparse and click, a flag with no default, a default that is a call, a C++ TCLAP argument, an alias after the name, a nushell `.named`, an invocation ranked before the registration, a no-hyphen name met as a dict value, a same-named field of another struct, and near misses (docs only, no site, a Rust clap field, no flag word, no flag).

What it does NOT do: it does not read a flag that has no quoted name (a Rust clap field, gflags `DEFINE_int32(name, ...)`), it does not follow a default through a variable or a call, and `def=` is the text of the argument, not the value in effect.
