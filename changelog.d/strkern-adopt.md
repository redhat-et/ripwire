### Changed — five case-insensitive and token-scan sites use the strkern kernels

`rw::strkern::ciFindLiteral( hay, needleLowered, from )` is the ASCII case-insensitive twin of `rw::strkern::find`: the same first-and-last-byte loop over a case-folded block, NEON, AVX2 and a portable scalar twin, returning exactly what a `tolower` copy followed by `find` returns (bytes at or above 0x80 are never folded). Five sites now call it instead of lowering a copy of the text per call: the LSP `workspace/symbol` name match, the handler-shape stub-phrase count, the HTML section parser's `findLower` and `startsWithLower`, and the doc-drift `findNoCase`; the clone tokenizer also classifies bytes from a table and skips comments with `memchr` / `strkern::find`. Output is byte-identical at every site. Each site alone runs 1.1-20x faster (for example `findLower` 0.05x and `findNoCase` 0.06x of the old time); whole-verb CPU on vscode and envoy moves by at most a few percent, because these scans are a small part of each verb.
