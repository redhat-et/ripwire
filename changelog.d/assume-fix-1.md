### Fixed — two release-build undefined-behavior sites on adversarial input: a 65,536-parameter list and a contradictory `engines.node`

A parameter list with 65,536 or more children (a Python `def` with 65,535 parameters and one default, for example) wrapped the 16-bit counters behind the minimum-arity fact, so an invariant check trapped the dev build and was silent undefined behavior in a release build. The counters are now 32-bit and the stored parameter count and minimum saturate at 65,535. A package.json `engines.node` clause whose ceiling is at or below its floor (`">=18 <0"`, `"^18 <0.0.0"`) broke a postcondition the same way; such a clause now reads as "admits anything", like an upper-bound-led clause, so `--test-gate` keeps `run_unknown="1"` instead of guessing. Neither input occurs in an ordinary repository, and neither value indexed memory or sized an allocation. New arms: the generated wide-list arm in `test/aritycheck.sh`, z27-z28 in `test/testgatecheck.sh`.
