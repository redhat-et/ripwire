### Fixed — the flagless map is served in pages when it is over the output ceiling

`ripwire DIR` prints a 200-row ranked map plus an inventory of every file the rows do not show. On GA1 DEV (11 repos, one tree each) 3 maps were over 30,000 characters (Newtonsoft.Json 52,858) and 5 over 24,000 — past Claude Code's inline limit, where the agent gets a file path and a 2,000-character preview instead of the map it orients with.

A bare map over 24,000 characters (the output ceiling, `src/outputceiling.h`) is now rendered whole, exactly as before, and served in pages cut between its own rows: the file groups and, inside a large inventory, its `ls` rows (the `<inv>` tag is re-sent around the part each page holds). Page 1 keeps the legend; every page's root says `page= pages= withheld_bytes= has_more=`, re-prices `est_tokens=` for the page, and names the next page as `next="--page-bytes=24000:K"` (plus `--exclude` / `--max-file-size` / `--no-ignore` / `--ignore-tests` when you passed them, so it maps the same files). The pages' rows rebuild the whole map. `--page-bytes=N` sets the page size and `--page-bytes=0` prints the whole map in one call. A map under the ceiling, and any map shaped by `--top-k`, `--max-tokens`, `--token-budget`, `--query`, `--rank-by`, a payload verb, `--json`/`--html` or a non-default `--legend`, is unchanged. `--page-bytes` beside a report verb now refuses instead of being read by nothing.

Measured on GA1 DEV (11 repos, one tree each): largest bare map 52,858 → 23,629 characters; maps over 24,000: 5 → 0, over 30,000: 3 → 0; on every repo the pages rebuild the whole map. Gate: `test/outputceilingcheck.sh` (arms M0–M9).
