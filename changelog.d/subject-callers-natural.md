### Fixed — `--for` prints the callers of the one function a sentence asks about

- `--for`: a sentence that names one function and asks what depends on it now gets that function's `<callers by="subject">` block, as the short subject already did. Examples: "I want to add a new parameter to transformNodes; what would that affect?", "who calls async_prepare_setup_platform and would break if its signature changed?", "I need to change how decompress_data works; what depends on it?". The plain-word limit now leaves out the task frame: question leads, pronouns, helpers ("I need to"), conjunctions and prepositions. The sentence also needs a dependents cue (change, add, affected, breaks, depends, calls, used, update, modify). A sentence without one reads as before, for example "how does X work", "where is X defined" or "how do A and B relate". The route does not change: a sentence never switches a ranked map to a name-exact answer, and the rest of the answer is byte-identical. Gate: `test/subjectanchorcheck.sh` arms SC.
