### Added — `@lang` scope selectors, `reflang=` disclosure, and the editor's declared language (#440, thanks @mpapis)

- `@rs` / `@cpp` / any known tag is now a selector on every name-taking verb: the answer is scoped to that language — unless it holds nothing, when foreign rows are still served AND the refusal sentence says so (`the matching language holds no definition; N in others`), exit code untouched. Case tolerance is parse-only: `@CPP` resolves like `@cpp`, emission stays canonical. An unknown tail REFUSES with the vocabulary, never silently ignoring it; `?` is display fallback, not vocabulary.
- An answer that anchored to a language says which and why: `reflang="rs" reflang-origin="explicit|context|corpus|file"` on the row, and where a list has no row to carry it (`--lsp workspace/symbol`, the picker answers), one `window/logMessage` ahead of the response — merged into the cap notice when both apply, fired only when something was answered.
- `--lsp` reads the document's declared language: a `didOpen` `languageId` that passes the alias map replaces the path convention for definition/references/hover (never for `workspace/symbol`, never against an explicit `@lang`, unmappable ids change nothing byte-for-byte). The map is config: compiled defaults seeded from the Zed extension's grammar names, overridable via `--lsp-langmap=FILE` > `$XDG_CONFIG_HOME/ripwire/lsp-langmap.toml` > `<root>/.ripwire/lsp-langmap.toml` > `~/.config/ripwire/lsp-langmap.toml`, malformed files disclose and stand down, declarations are keyed by disk path so an index rebuild cannot misattribute them, and raw client strings never enter any protocol echo — only ripwire tags and the origin word `client` flow onward. `--lsp-langmap` alone refuses rather than silently doing nothing.
- The name tower is language-first: the 432 entry above was corrected to match, since D re-ranked kind under language.
