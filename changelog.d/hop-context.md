### Added — `--path` and `--connect` hops print the call site, the call and the callee's signature

A `--path` hop row and a `--connect` `<e>` row used to name only the two definitions an edge joins, so the next step was opening the caller to find the call and the callee to read its parameters. Each hop now also prints `site="file:line"` (a call in the caller that names the callee: one whose argument count the callee accepts first, then one qualified by the callee's owner; `sites="N"` when the caller has more than one such line), `call="…"` (that call's text from its line start, or from the statement when the caller is a one-line function, whitespace collapsed, joined across up to 3 lines while its parentheses are open, at most 120 bytes) and `sig="…"` (the callee's declaration signature, at most 160 bytes). The site is a name match, not proof that this call is the one the edge binds, and the legend says so; `site_by="first"` marks a pick among equally fitting lines when the caller also calls another callee of that name, and `site_by="nofit"` a site whose argument count the callee does not accept. Call text is redacted before any cut, and no cut lands inside a token or a redaction, so a credential prints whole-redacted or not at all; a callee name inside a redacted run withholds `call=` (`hop_redacted=`). On `--path` the first reaching pair prints all three and later pairs print the site only; on `--connect` a callee's signature prints once per group and not where its join row already shows it. A call or signature whose file cannot be read, or whose length changed since indexing, is left out and counted (`hop_unread=`), and a length change leaves the site out too; a site whose text does not name the callee is counted too (`hop_notext=`); an edge with no call naming the callee in its caller prints no site (`hop_nosite=`) but still prints the callee's `sig=`. Under `--max-tokens`, `--connect` drops these attributes first (`sig=`, then `call=`, then `site=`, named by `hop_shed=`) and only then trims as before. Two `<e>` rows that would read alike (two same-named targets reached from one caller) now print `tp=`/`fp=`, the definitions they join. The MCP `path_between` and `connect` tools print the same rows. `RIPWIRE_NO_HOP_CONTEXT=1` turns the attributes off. New gate `test/hopcontextcheck.sh` covers C, C++, Python, TypeScript, Go and Rust hops, the site pick (owner, argument count, ties), credentials a cut would split, hops with no site, unreadable and edited files, the shed order, and one reference pass for a 40-hop path.
