### Changed — `--stray-content` skips the call-graph build it never reads

`--stray-content` answers from git: `crossref::computeStrayContent` takes the root and the ref filter. Its `--abi` and `--plan` modes read the ingest as well, but `runCrossRef` passes the call graph to none of the three. A run where `--stray-content` wins dispatch and no modifier reads the graph (`--pin-census`, `--metrics`, `--for`, `--exemplar`, `--pack-signatures`, `--from-trace`, `--run-trace`, `--pack-task`) now skips `buildGraph`, the same skip `--deps` and `--arch` already take. The output does not change: `test/straynographcheck.sh` compares stdout and the exit code against the same call with `--metrics`, which still builds the graph, for the bare sweep, the `=SUBSTR` filter, `--abi`, `--plan` and a filter that matches no ref. It also checks that a skipped run neither stores a graph in the warm snapshot nor drops one that a `--callers` run stored.
