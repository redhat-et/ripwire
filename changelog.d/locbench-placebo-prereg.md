### Added — LocBench placebo and fair-lexical control arms, and a pre-registered replication of the structural-tools placebo study

`bench/locbench/run_locbench.py` gains four matched-budget control arms: `for-matched` (ripwire's `--for` rows cut to the budget), `placebo` (ripwire-rendered rows from files the real answer does not name), `placebo-shuffle` (the real rows, reordered) and `lexical` (whole-file BM25 with identifier splitting). Each arm is exactly the production `--for` payload's byte size and uses the identical `--format=candidates` format. `--emit-payloads=DIR` seals every arm's payload with a sha256 manifest. `bench/locbench/PREREG_PLACEBO.md` freezes the arms, the models (Qwen3-4B and Qwen3-14B locally, Claude Haiku 5.5 on the API), the held-out task set and its seal, n and the power arithmetic, the absolute bars and the stopping rule for a live round that has not run. It also records what result would count against ripwire. Gate: `test/locbenchplacebocheck.sh` (42 checks with a ripwire binary present, red on the base commit).
