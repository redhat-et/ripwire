### Added — `asserted=1` beside `tested=1`: a test that reaches a row is not a test that checks anything

- **What it says.** `tested=1` means an indexed test reaches the row over call edges, and #770's legend says that is reached, not asserted. `asserted=1` now rides beside it where at least one reaching test asserts: its own body, or a test-scoped helper it calls (over test symbols only, transitively), makes a call from its language's assertion vocabulary. An assertion in production code on the path never counts. Rahman et al. (arXiv 2610.33708, *Covered Is Not Checked*) found 18% of covered branch outcomes could change with no test failing; this is the static half of that gap.
- **Where.** The `--callers`, `--callees` and `--impact` rows (XML, JSON `"asserted":true`, and a present-only `<asserted>` column in `--format=columnar`), CLI and MCP alike. The map's `--metrics` rows, `--pack-task` and `--for` keep `tested=` alone for now; `QMetrics::asserted` carries the column for them.
- **Vocabulary.** One `langfacts.h` column, `assertionCalls`, one row per language: C/C++ (`assert`, GoogleTest, Catch2, Boost.Test, Unity, Check, cmocka), Python (the `assert` statement, unittest, numpy.testing, mock, pytest.raises), TypeScript/JavaScript (`expect`, node:assert, Chai), Go (`t.Errorf`/`Fatal`, testify, Gomega), Rust (`assert*!`), Java (JUnit, AssertJ, Hamcrest, Mockito `verify`), Kotlin, C# (`Assert.*`, FluentAssertions, Moq), Ruby (minitest; RSpec `expect` in a named helper), Elixir (ExUnit), Lua (`assert`, luaunit), GDScript (GUT) and Clojure (`is`/`are`), each with a gate control. Scoped out: Bash (a shell test checks exit codes, and its reach is subprocess-driven, outside the graph), Dart (package:test registers every test as an anonymous callback inside the named function `main`, so counting it would over-claim), and Swift, Objective-C and PHP (on XCTest and PHPUnit fixtures `tested=` itself never fires, so no control can hold).
- **Honesty.** Absence means none found, never none exists: the match is by name, like every call edge, and an assertion call in a reaching test is not proof it checks that row. An anonymous test callback (Jest/Vitest/Mocha, RSpec `it`, busted `it`, clojure.test `deftest`) has no symbol of its own: its calls belong to the file's module scope, which stands in for every example in the file. Its assertions are therefore never counted (counting them would over-claim); a named test function in those languages still counts.
- **Cache.** `queries/python/tags.scm` now records the `assert` statement as a call named `assert`, so the ingest cache version moves to 57 (above main's 55).
- **The served QMetrics record (#756).** The record (version 2) now stores `asserted` beside `tested`. It refuses a stored asserted row that is not a tested row. Its key gains an `asserts` component (every Call/Macro site of a test symbol, by its bytes) and the in-edge CSR. An assertion call is usually external, so adding one moves no edge; without that component a served record would hand out a stale `asserted=`. `RIPWIRE_STATS=1`'s `[verbfs] qmetrics` line also says `asserted=N`.

Gates: `test/assertedcheck.sh`, and `test/qmetricscheck.sh` I7 (with its NOASSERTS mutant).
