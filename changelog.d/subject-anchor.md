### Fixed — `--for` anchors the symbol a subject names, and says when no source defines it

- `--for`: a symbol named exactly in a descriptive subject is the anchor. Plain words beside it (`new`, `parameter`, `default`) no longer anchor the wrong definitions, decline the route or lose `<callers>`; `route=` lists them under `dropped:`. A route that was declined for a word gives up its ranked map for the symbol only where the answer prints the symbol's body and its callers: the name is one function in the whole index and its body fits the single-anchor allowance. Otherwise the map stays and a conceptual route whose subject names one function carries `<callers by="subject">` on top. The MCP `for` verb, which serves signatures only, keeps its map.
- `--for`: `confidence="high"` on a name-exact route needs a source definition behind the anchor. An anchor only a test, doc or data file defines reads low, and `route=` says why. A plain word never vouches for a subject that spells a name: `max_concurrent_queries read`, whose key lives in a data file, reads low although `read` is defined in source.
