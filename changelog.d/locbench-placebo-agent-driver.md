### Added — the LocBench placebo round's agent driver

`bench/locbench/agent_loc.py` is the agent driver `bench/locbench/PREREG_PLACEBO.md` froze before it existed. One episode gives a model the issue, read-only `grep`/`read` tools over the git-tracked files of the checkout at `base_commit`, and at most one sealed payload (arms A0/A1/A2/A3 plus A2s/A1p). Every payload is checked against its sha256 manifest, and a mismatch refuses the episode. ripwire is never on the child's PATH. The limits are 15 turns and 250,000 cumulative input tokens, and an episode that never submits is a counted miss. Each record carries the model, the `resolved_model` read back from the provider, the arm, the seed (the replicate index, because no provider exposes a sampling seed), the billed credential's name, tokens split by cache category, tool calls by kind, and a saved transcript. `run_locbench.py` gains `--instances` (score only the named rows) and keeps `universe_files` in a seal run's JSON for the driver's scorer. Gate: `test/locbenchagentcheck.sh` (64 checks with a stub model and a fake `claude`, no network; red on the base commit).

`bench/locbench/run_pilot.sh RESULTS_DIR` runs the 96-episode Haiku pilot from a logged-in terminal. It checks usage after 12 episodes, priced at the prereg's own table, and stops above 2× the central estimate. Re-running resumes where it stopped.
