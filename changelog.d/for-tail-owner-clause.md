### Fixed — `--for` defines a module-scope owner that only its `<tail>` names

The legend clause for a file's module scope (`<file-scope>`, `t="modscope"`) was decided from the `<d>`/`<hops>` row head alone, before the header. An owner that ranked past that head still reached the answer as a `<tail>` pointer row (`sym="…,<file-scope>"`) and was printed with no definition. The clause now also rides when a printed tail row names an owner; an answer with no owner row is unchanged. Reported by the M5 session (affectedcheck (8f) on #790's tree, `--for --legend=full 'emit xml attributes'`). `test/affectedcheck.sh` (8g) holds it on a fixture whose only owner ranks into the tail.
