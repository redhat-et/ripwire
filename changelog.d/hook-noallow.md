### Security — the opt-in tool-call router hook no longer approves the call it comments on

`hooks/ripwire-claude-toolroute.sh` is the opt-in Claude Code PreToolUse arm that suggests a ripwire command when the agent reaches for a recursive grep or a source-file Read. When it spoke, it answered `permissionDecision:"allow"` beside its `additionalContext`. In Claude Code, `"allow"` skips the user's permission prompt. So in a session with this hook installed, any Bash or Read call it chose to comment on ran without the prompt the user had configured. That included a compound Bash command whose first segment was a recursive grep (`grep -rn X src/ && <anything>`). The hook now returns `additionalContext` only, and the user's own permission flow decides, as with the other ripwire hooks. The suggestion text is unchanged.

No other hook returned a decision on its default path. One more could, but only when set by hand: `ripwire-nudge.sh --agent-brief` added `permissionDecision:"allow"` when `RIPWIRE_AGENT_BRIEF_DECISION=allow` was exported. That was a probe knob no installer registered. It is **removed**: the variable is no longer read, and the mode never returns a decision. No hook returns `deny` or exits 2.

Gate: `test/hookcheck.sh` section (15). It runs every hook under `hooks/` with no argument and with each mode the hook accepts, under the meter arms treatment, control and unset, on 13 payloads (the compound Bash case included). An extra arm runs every `--agent-brief` mode with `RIPWIRE_AGENT_BRIEF_DECISION=allow` exported, which proves the knob is gone, not just unset. That is 650 runs. It fails if any output carries `permissionDecision` or a top-level `decision`, or if any run exits 2. On the base, the tool-call router failed 8 runs, and the knob arm failed 4 more (`ripwire-nudge.sh` and `ripwire-codex-nudge.sh`, on the Agent and Task payloads). Arm PD2 requires the router to actually answer on the grep and compound payloads, and PD4 requires `--agent-brief` to answer under the knob arm, so neither check can pass on silence. Four hooks printed nothing on these payloads, so PD1 says nothing about them: the two prompt routers and the two legend-seen hooks. Their own gates (`test/routehookcheck.sh`, `test/legendseenhookcheck.sh`) already assert that they return no decision.
