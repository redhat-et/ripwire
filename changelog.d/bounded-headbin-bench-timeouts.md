### Fixed — the HEAD-binary build and the bench harnesses are bounded: no unlimited `make -j`, and a timeout or a signal-kill is its own recorded state

`test/lib/headbinlib.sh` built the HEAD comparison binary with a bare `-j`, which under make means unlimited jobs; it now uses `headbin_jobs`: `CMAKE_BUILD_PARALLEL_LEVEL`, then `RIPWIRE_HEADBIN_JOBS`, then the CPU count under GitHub Actions, otherwise `max(1, min(ncpu/2, GiB/8))` (an invalid value is ignored with one stderr line). `bench/recalleval/run_r3diff.py` now defaults to `min(6, ncpu/2)` parallel jobs. Every whole-repo ripwire spawn in the bench scripts now has a timeout, and a killed or timed-out run is recorded as `timeout`/`killed(signal=N)` (or the script's existing state family) instead of an error code or, worse, a graded partial answer; a normal run's output is byte-identical. CI's staging step is unchanged. Lane M2 (`bf3fc5e62`, `bf9b44395`).
