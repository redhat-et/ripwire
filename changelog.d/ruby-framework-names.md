### Fixed — in a Rails tree, `scope.where`, `rows.pluck`, `x.blank?` and `Time.zone.now` no longer bind the one application method of the name

A call whose receiver no rule typed reaches the name tier with its spelling as the only evidence, and a name with ONE in-tree
definition bound to it. In a Rails application those calls are mostly on a relation, a record or a value ActiveSupport
extends: `scope.where( … )` bound a test double's `where`, `params[ :q ].present?` a value class's `present?`,
`Time.zone.now` a library class's `now`, `record.errors` a service object's `errors`. The builtin-method name gate already
asks for evidence before such a call binds when its name is a Hash, Array or String method (`h.fetch( k )`); it now asks the
same for the methods ActiveSupport gives every object and every zone (47 names: `blank?`, `present?`, `try`, `now`, `parse`,
`name`, `to_s`, …) and the methods ActiveRecord gives a record, a relation and a model class (893 names: `where`, `pluck`,
`find_by`, `save`, `update_columns`, `errors`, …), each table generated by one recorded command from the Rails 8.1.4 gems
(`src/externalnames.h`). A table joins only in a tree that writes a constant under the framework's namespaces (`<
ActiveRecord::Base`, `extend ActiveSupport::Concern`, `Rails.logger`) and does not open its home constant, so the Rails gems'
own trees keep their maps. The edge stands when the caller's file names the bound method's class; otherwise the call is
declined and counted (`declined_calls=` on the definition it could have meant), never retargeted. A split with one evidenced
arm stays a split. `test/rubyframeworknamescheck.sh`.

Measured with `--pin-census` on two Rails applications and the ActiveRecord and ActiveSupport `lib/` trees, Ruby call sites,
the example-group fix vs this change:

| | bound | external | declined |
| --- | ---: | ---: | ---: |
| application A, before | 38,755 | 60,138 | 23,643 |
| application A, after | 35,750 | 60,200 | 26,586 |
| application B, before | 61,358 | 102,687 | 33,183 |
| application B, after | 55,205 | 102,753 | 39,270 |
| ActiveRecord `lib/`, before | 11,947 | 1,166 | 4,771 |
| ActiveRecord `lib/`, after | 11,733 | 1,188 | 4,963 |

On application B the declines are `pluck` 1,072, `where` 1,023, `blank?` 1,014, `present?` 965 and `errors` 508 at the
head; on application A `where` 419, `blank?` 413, `now` 313, `association` 252 (FactoryBot's) and `errors` 223. Sampled by
hand, the edges removed were wrong 20 of 20 on B and 19 of 20 on A, and 15 of 15 and 14 of 15 among the generic names
(`errors`, `reload`, `group`, `id`, `parse`). The calls now refused as external (every target one the call cannot reach)
were wrong 12 of 12. ActiveRecord's own tree loses 214 bound sites to `present?`, `blank?` and `name` (its code uses
ActiveSupport), sampled 15 of 15 wrong. ActiveSupport's census is identical; its map moves only by the `declined=` legend sentence
this change widens (`est_tokens` 13,445 → 13,444).

Known floors, each pinned in the gate or stated in `src/graph.h`: an object handed in with no mention of its class in the
file loses the by-name edge to `declined_calls=` (the two true edges among the 70 sampled were such: a block over an
association's records, a struct passed as a parameter). The evidence is the tree's, not the file's. A split with one
evidenced arm is kept whole, false arms included. A member call whose only bound target was a def nested in a method is
now external even when the right definition is elsewhere in the tree (21 `reflection.name` sites in ActiveRecord's own
tree, each bound to a nested `name` before).
