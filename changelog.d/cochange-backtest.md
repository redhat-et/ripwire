### Documented — a time-ordered backtest of the co-change partners against two baselines

`bench/cochange/` replays real commits to ask how often `--situ`'s co-change partners name a file that the same commit also touched, once that file is held out. It compares them against same-directory files and an independent Python co-commit count. Each arm sees only history reachable from the commit's first parent, inside the same 18-month window anchored on the parent. The protocol was stated in the README before the first run. An external incomplete-change dataset (arXiv:2609.34317) was checked first and publishes no artifact. `test/cochangebacktestcheck.sh` builds a git fixture with a known answer. It proves that the harness scores Hit@k correctly, and that a coupling which exists only after the commit is never found, while a deliberate `--leak-future` mode does find it.
