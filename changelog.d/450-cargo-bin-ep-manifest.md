### Added — `--for` shows a Cargo `[[bin]]` entry and the `main` it names (#450)

- `--for` manifest entry points now read Cargo.toml `[[bin]]` tables (group `bin`), resolving each bin path to its `main` function; an omitted `path` follows Cargo's default (`src/main.rs` for the package's own name, `src/bin/<name>.rs` otherwise), and a crate with no `[[bin]]` (and no `autobins = false`) lists its own bin at `src/main.rs` when the task names the package or asks about running a binary (run, bin, binary, cli, command, executable, launch, main, entry). A `path` with `../` or Windows `\` separators names the file it points at. Not read: the binaries Cargo auto-discovers (`src/bin/*.rs`, and `src/main.rs` beside declared `[[bin]]` tables) and `src/bin/<name>/main.rs` as a default path. Gate coverage in `test/epmanifestcheck.sh` (issue #450). Thanks to @llvm-x86 for the reader, the fixtures and the Cargo inference cases.
