### Changed — clang-tidy: a ratchet on the advisory baseline, and the swappable-parameters check is off

Contributor-facing; no output of `ripwire` changes. Two gating checks join CI's `style` job. `scripts/tidycheck.sh --ratchet` runs a small high-signal set of clang-tidy checks (unchecked `optional` access, use after move, dangling handles, signed-char misuse, throwing static initialisation and four more) on every pull request and fails on any finding that is not already a row of `.clang-tidy-baseline.txt`; exception escape, too slow to run per pull request, is held to the same rule from the nightly report. `test/tidyratchetcheck.sh` holds the baseline itself to a per-check ceiling in `.clang-tidy-ratchet.txt`: a change that adds rows fails, and one that fixes a row lowers the ceiling in the same commit, so the count only goes down. Both are proved on planted findings. The nightly report over the full catalogue stays advisory. `bugprone-easily-swappable-parameters` is disabled: it was 612 of the baseline's 967 rows, and each row named a signature shape rather than a defect; `--quality-delta`'s params kind covers parameter-list growth instead. This does NOT mean the remaining baseline rows are triaged: they are still to fix or to justify.
