### Changed — a correct call edge no longer lowers its caller's lexical rank

The lexical ranker behind `--for`, `--query` and the other ranked verbs adds the names a symbol calls to that symbol's searchable text. Those names also counted toward the text's length, so a call whose name did not match the query made its caller look longer and scored it lower: when the resolver bound one more call correctly, the caller could drop out of an answer (a Home Assistant light's `async_turn_off` fell out of the file list when its `self.bridge.async_request_call` call bound). Callee names now add term weight and no length: a bound call raises its caller's score when its name carries a query word and leaves the score unchanged otherwise, in every language. Each name is tokenized once per query instead of once per call edge. Gate: `test/calleetextmonocheck.sh` (Python, TypeScript, C++ and Rust fixtures).
