### Changed — `--for` anchor choice: a name with no definition at all no longer commits the route

- `--for` and the MCP `for` verb: a name-exact anchor that resolves to NO definition (an env var or an error code the index stores no definition of, shown as `NAME(syntax)` in `route=`) no longer commits the route. As with a test-only anchor among several copies, the words rank instead (`route="subtoken+body:broad; anchor has no source definition (…), not committed: ranked as words; hint anchors: NAME(syntax)"`), confidence reads low as before, and the `<shortkey>` and `<lit>` blocks still print. The ranked rows now carry the bodies of the source code that reads the name. A name with ONE non-source definition keeps its name-exact route.
