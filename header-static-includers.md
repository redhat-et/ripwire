### Fixed — a C `static` in a header binds from the files that include it

A `static` function or variable defined in a header is visible to every file that reaches the header over resolved `#include` edges, directly or transitively, and value references from those files now bind to it; a `static` in a `.c`/`.cc`/`.cpp` file stays private to that file, and an unresolved `#include` proves nothing (no bind, and the count stays a floor). Confirmed with the untied-declaration fix above on a fresh blind gold set (no cell lost a group, within the byte bar); on its own it changed no confirmation answer, and it changes two development `--for` cells through the shared index.
