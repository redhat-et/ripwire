METHODOLOGICAL DEFECT IN THIS ROUND'S OWN PREREG, recorded because it nearly laundered noise into an
advance. The bar was ">= +2.00pp multi-file" on a 43-instance stratum, where ONE instance is 2.33pp.
The bar was therefore below single-instance granularity and meant nothing stronger than "flip at
least one". It was NOT moved after the grid ran — that would be the exact laundering the PREREG
forbids — so the held-out run was spent as promised and reported as it fell. Future thresholds on
this stratum must be stated in INSTANCES with a floor of >= 3, not in percentage points.

FOURTH REJECTION, SAME SIGNATURE. r1_anchorhop, r1cpp_anchorhop, r4_siblift and now r5_pooling all
reshuffle inside the top-k without moving the @10 frontier. r5 differed on the axis r4's post-mortem
blamed — it chooses no neighbour — and still did not move it. That narrows the diagnosis: the problem
is not WHICH files get promoted, and not HOW they are placed. Every one of these four mechanisms
re-weights evidence the query already produced, and for the sibling files that define this stratum
the query produced NO evidence to re-weight.

WHAT THE ROUND 4 DECOMPOSITION SAYS ABOUT WHY (held-out, 22 multi-file failures):
  9  sibling ranked but too low (median rank 26)  <- the only bucket a reranker can reach
  7  sibling indexed but scoring ~zero on the query
  4  whole instance missed (primary at rank 39, 70)
  3  gold files carrying no code symbols at all
Pooling could only ever have reached the 9, and on held-out it reached none of them: its inputs are
the same query-derived symbol scores that already ranked those siblings at 26.

WHAT SURVIVES. r6 structural expansion, seeded from a CONFIRMED top-ranked gold file rather than from
a mention anchor, is the first candidate that would introduce evidence the query did not supply. Its
feasibility probe (bench/locbench/results/r6_expansion/) found the required edge present for 28 of 40
gold files (70%), with the caveats recorded there. That is a different failure mode from these four,
and it is the only one of them with a verified substrate.
