# r3.1 pre-registered protocol amendments (for the next run of this benchmark)

**Registered 2026-08-03, after the r3 run, BEFORE any r3.1 arm runs.** r3's numbers stand as
published; these amendments fix the two loss buckets r3's own investigation classified as
harness/criterion artifacts, plus the verifier's metric findings — so an r3.1 re-run measures the
tool, not the harness. Anything not listed here re-runs exactly as r3 froze it (same 12 questions,
same gold, same corpus pin, same metric implementation).

1. **C6 ladder (q11, q12)**: rung 1 becomes `--grep=<literal> --grep-context=7` (the existing
   context flag; r3 measured +263 t over bare `--grep` and it surfaces the adjacent `raise`).
   Rung 2's dynamic rule is replaced: chain `--uses=<X>` off the first `raise X` / `except X`
   visible in rung 1's context blocks (r3's rule regex-scanned a context-free window and could
   never fire).
2. **C3 criterion (q05, q06)**: `--affected` arms are scored on gold FILES only — the verb's
   documented schema is path-only, and demanding a class-name token from it is a criterion bug
   (r3 bucket, q06). The naive arm keeps its full criterion; this is verb-appropriate gold, not a
   relaxation of the question.
3. **B-arm token accounting (verifier F1/F2)**: the packaging decomposition ships in the metric —
   charged tokens are reported as (content, packaging) pairs for B/B′/D, and the headline uses
   content-attributable deltas only. The question message is excluded from both scoring and
   charging (r3 excluded it from scoring only).
4. **Timing symmetry (verifier F8)**: headroom timings gain a fresh-process variant beside the
   in-process one; both are labeled.
5. **Recovery-cost rule (verifier F4)**: any "documented recovery" figure quoted in a loss bucket
   must be re-run by the verifier from the exact argv before publication — r3 shipped two wrong
   ones from investigator estimates.

Trigger for running r3.1: after the module-constant indexing fix and/or an accepted r4/r5 ranking
candidate lands — the point of the re-run is to measure whether the four r3 ranking losses and the
one missing-symbol-kind loss actually closed, on the frozen question set, with the artifact rungs
no longer confounding the count.
