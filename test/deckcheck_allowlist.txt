# deckcheck_allowlist.txt — deckcheck.sh's explicit false-positive allowlist.
#
# Format: TOKEN<TAB>one-line reason. Every entry MUST carry a reason (deckcheck.sh enforces this —
# a bare token with no tab+text fails the gate as loudly as an unlisted fabrication would).
#
# Two categories legitimately land here (deckcheck.sh's own job is to tell these apart from a
# fabricated flag, never to hide one):
#   (a) a REAL ctxpack flag that `--help` deliberately does NOT print — a CTXPACK_DEV/env-gated
#       experiment kept out of the public catalog on purpose, a deprecated alias kept working for
#       back-compat, or a flag that belongs to a subcommand (`wrap`) whose own flags aren't
#       enumerated in the top-level --help text.
#   (b) a flag that belongs to a DIFFERENT tool, quoted verbatim inside a worked example
#       (xmllint / git / cmake / aider / this repo's own install.sh) — never a ctxpack flag at all.
#
# deckcheck.sh also fails if an entry here is no longer used anywhere in the scanned sources
# (stale-allowlist rot) — delete a row the day its last reference disappears.
